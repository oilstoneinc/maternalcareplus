## Regenerate PDF

**Option A — Browser (no tools needed)**  
1. Open `maternalcare-plus-pitch-deck.html` in Chrome or Edge.  
2. Press `Ctrl+P` → Destination: **Save as PDF**.  
3. Layout: **Landscape** · Margins: **None** · Background graphics: **On**.

**Option B — Chrome headless (Windows)**  
```powershell
& "$env:ProgramFiles\Google\Chrome\Application\chrome.exe" `
  --headless --disable-gpu --no-pdf-header-footer `
  --print-to-pdf="docs\MaternalCare-Plus-Pitch-Deck.pdf" `
```
